# Insurance_Risk
- Phân tích rủi ro bảo hiểm xe cơ giới và định giá gói bảo hiểm dựa trên hồ sơ lái xe sử dụng Học máy.
- Đánh giá xác suất xảy ra tai nạn của khách hàng mua bảo hiểm dựa trên hồ sơ cá nhân, loại xe và lịch sử lái xe, từ đó giúp công ty bảo hiểm định giá gói sản phẩm tối ưu, giảm thiểu tỷ lệ bồi thường quá mức.
- Công nghệ & Mô hình: Python, Scikit-learn, Thư viện xử lý mất cân bằng dữ liệu. Mô hình: Tweedie Regressor (đặc thù cho ngành bảo hiểm), Random Forest, CatBoost.
